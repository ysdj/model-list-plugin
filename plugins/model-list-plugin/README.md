# model-list-plugin

Synchronize model metadata from the API configured in Codex or Claude Code. The plugin includes macOS and Windows executables. See the [repository README](https://github.com/ysdj/model-list-plugin) for installation and synchronization behavior.

Install the plugin from Claude Code with `claude plugin install model-list-plugin --marketplace ysdj/model-list-plugin --scope user`. The first session reads the client settings and begins synchronization. Use `/model-list-plugin:model-list-plugin` to inspect its status or sync now. The plugin checks for updates automatically.
